## 人類進化のあゆみ（縦画面・学習用）

原人から現代人まで、5つの章を体験しながらたどります。
「ゲームとして面白くする」より **事実を正しく伝える** ことを優先しています。

| 章 | 体験 | 操作 |
|---|---|---|
| 原人（ホモ・エレクトス） | 火を絶やさない | タップして薪をくべる |
| 旧人（ネアンデルタール人） | 掘り出す | ドラッグして土を払う |
| 新人（ホモ・サピエンス） | 線を引く | なぞってオーカーを塗る |
| 農耕のはじまり | 種をまく | タップ。世代を重ねると粒が大きくなる |
| この先 | 想像であることの明示 | — |

最後に**年表**が出ます。原人・旧人・新人の生存年代を並べた棒がはっきり重なり、
ネアンデルタール人とホモ・サピエンスの26万年の併存が目で見えるようにしてあります。

### 事実の扱い

本文はすべて [docs/human-evolution-facts.md](docs/human-evolution-facts.md) の裏取り結果に基づき、
3つの色で区別しています。

- 🟢 **たしかなこと** — 研究者の間で争いがない
- 🟡 **まだわかっていないこと** — 議論が続いており断定できない
- 🔵 **むかしと変わったこと** — かつての通説が覆った

制作中に、教科書に載っていた3つの説が現在は否定されていると分かったため、
いずれも「むかしと変わったこと」として扱っています。

- 北京原人が50万年前に火を使った証拠とされた灰 → 水に運ばれた堆積物だった
- ネアンデルタール人の「花の埋葬」→ 花粉はハナバチが運んだ（2023年）
- 芸術は4万年前のヨーロッパで始まった → 7万年以上前のアフリカにさかのぼった

本文は小学生が読む前提のやさしい言葉で書いています。ただし出典の論文名は、
書き換えると調べ直せなくなるため原文のままです。

### 画面の使い方

**絵はウィンドウ全面に描き、文字と操作だけを 9:16 の帯に置いています。**
以前は絵ごと 9:16 に閉じこめていたため、横長のPCでは画面の約3割しか使えず、
残り7割が黒帯でした。いまは森も洞くつも畑も画面の端まで広がり、
火あかりも左右いっぱいに届きます。

座標のきまりは2つだけです。

- `env.W / env.H` … 帯の大きさ。地平線や火の高さなど**たての位置ぎめ**に使う
- `env.x0 / y0 / x1 / y1` … **実際に塗ってよい範囲**。横長のPCでは `x0` が大きなマイナス

体験（`js/act/`）は帯の座標のまま書けます。キャンバスの原点を帯の左上に
ずらしてあるためです。星・木・小石などの個数は帯を基準にした密度から出しており、
画面が広がったぶんだけ自動的に増えます。

背景は画面サイズが変わったときだけ1枚の絵として描き、以降は貼るだけにしています。
全画面ぶんを焼くので、背景だけ倍率を落として（`env.bgDpr`）焼いています。
同じ理由で、ふちの暗がり・光の玉・手前の葉も1枚焼いて使いまわしています。

炎は多角形ではなく粒を重ね、土は升目ではなく1枚の絵をぼかしながら消しています。
粒は「小さく・多く・薄く」散らしています。大きい粒を狭い範囲に重ねると、
加算合成で中心が白く飽和して電球のような球になり、色の移りかわりも薪も見えません。

## EVOLUTION RUNNER（横画面・アクション）

速く走るほど進化し、止まれば退化する 2D ランニングアクション。
森の猿から始まり、原人 → 狩猟民 → 現代人 → サイボーグへと5段階の進化を駆け抜けます。

### 操作

| 入力 | 動作 |
|---|---|
| `SPACE` / `↑` | ジャンプ（サイボーグのみ2段ジャンプ） |
| `X` / `↓` | 攻撃（引っかき → 棍棒 → 投槍 → ドローンパルス → 貫通ビーム） |
| `SHIFT` | ブースト（DNAが燃料） |

スマートフォンは画面下のタッチボタンで操作できます。

### ルール

- **速度が進化ゲージ**: 一定速度に到達すると次の時代へ自動進化し、落ちすぎると退化する
- **進化すると体が変わる**: 跳躍力・滞空時間・武器の射程・ブースト燃費が段階的に向上する
- **ニアミス**: 障害物ギリギリをすり抜けると加速し、コンボ倍率が上がる
- **⚠ 跳ぶな 表示**: 蜂の巣・氷柱・エネルギー天蓋など、上から迫る障害物は跳ぶと当たる
- サイボーグで限界速度に到達するとクリア

### 設計メモ

障害物の配置には「跳ばないと越えられない障害物」と「跳ぶと当たる障害物」を
同じ編成に混ぜないという制約を設けています。ジャンプの弧が固定のため、
両者が近接すると跳んでも跳ばなくても当たる回避不能パターンが生まれるためです。
全31編成 × 各時代3速度でジャンプのみの回避解を全探索し、回避不能な配置が
存在しないことを確認しています。

## ローカルで動かす

縦画面版は ES モジュール構成のため、**ファイルを直接開くと動きません**（CORS）。
簡易サーバー経由で開いてください。

```bash
python -m http.server 8123
# http://127.0.0.1:8123/        縦画面版
# http://127.0.0.1:8123/wide/   横画面版
```
