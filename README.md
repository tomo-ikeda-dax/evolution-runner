# 人類進化ランナー 🧬 EVOLUTION RUNNER

速く走るほど進化し、止まれば退化する 2D ランニングアクション。
森の猿から始まり、原人 → 狩猟民 → 現代人 → サイボーグへと5段階の進化を駆け抜けます。

**▶ [ブラウザで遊ぶ](https://tomo-ikeda-dax.github.io/evolution-runner/)**

外部ライブラリなしの HTML + Canvas 単一ファイル構成です。
「ゲームスタート」を押すと、槍を持った原始人の実写風オープニング映像（10秒・スキップ可）が流れてから本編が始まります。

## 操作

| 入力 | 動作 |
|---|---|
| `SPACE` / `↑` | ジャンプ（サイボーグのみ2段ジャンプ） |
| `X` / `↓` | 攻撃（引っかき → 棍棒 → 投槍 → ドローンパルス → 貫通ビーム） |
| `SHIFT` | ブースト（DNAが燃料） |

スマートフォンは画面下のタッチボタンで操作できます。

## ルール

- **速度が進化ゲージ**: 一定速度に到達すると次の時代へ自動進化し、落ちすぎると退化する
- **進化すると体が変わる**: 跳躍力・滞空時間・武器の射程・ブースト燃費が段階的に向上する
- **ニアミス**: 障害物ギリギリをすり抜けると加速し、コンボ倍率が上がる
- **⚠ 跳ぶな 表示**: 蜂の巣・氷柱・エネルギー天蓋など、上から迫る障害物は跳ぶと当たる
- サイボーグで限界速度に到達するとクリア

## 時代ごとの障害物

| 時代 | 障害物 | 風景 |
|---|---|---|
| 原始の森（猿） | 倒木・大蛇・突進イノシシ・吊り下がる蜂の巣 | 密林、垂れ蔓、舞い落ちる葉 |
| サバンナ（原人） | 転がる巨岩・獣骨の山・野火・襲いかかるハゲワシ | アカシア、熱風の火の粉 |
| 氷河期（狩猟民） | マンモス・サーベルタイガー・氷の裂け目・凍った倒木・垂れ下がる氷柱 | オーロラ、吹雪、マンモスの群れ、骨と毛皮のテント |
| 現代都市（現代人） | 工事バリケード・パイロン列・放置タクシー・落下しかけの看板 | ビル群、雨 |
| サイバー未来（サイボーグ） | 急降下ドローン・警備ドローン・プラズマ柱・レーザーゲート・防壁ユニット・暴走ホバーカー・エネルギー天蓋 | ネオン都市、地平線グリッド、データ片 |

## 設計メモ

障害物の配置には「跳ばないと越えられない障害物」と「跳ぶと当たる障害物」を
同じ編成に混ぜないという制約を設けています。ジャンプの弧が固定のため、
両者が近接すると跳んでも跳ばなくても当たる回避不能パターンが生まれるためです。
全31編成 × 各時代3速度でジャンプのみの回避解を全探索し、回避不能な配置が
存在しないことを確認しています。

```bash
python -m http.server 8123

```
